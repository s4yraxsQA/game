# Веб-версия игры для itch.io

Это ветка `web` с готовой веб-сборкой мини-футбола.

## Как загрузить на itch.io

1. Скачайте файлы из этой ветки (`index.html`).
2. Заархивируйте `index.html` в ZIP (файл должен быть в корне архива, без папки).
3. На itch.io создайте проект типа **HTML**.
4. Загрузите ZIP и отметьте "This file will be played in the browser".
5. Установите размер viewport (например, 800x500).

Игра готова к загрузке!
